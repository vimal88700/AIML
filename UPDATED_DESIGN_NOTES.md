# Updated design

The archive now uses a slow moving digital grid, subtle scanline overlay, terminal-style staggered name reveal, and Framer Motion LayoutGroup/layoutId card-to-profile morph. Profiles use glassmorphism bento tiles for Status, Race, Hobbies, Goal, contact, and social fields. The published-only Media Vault supports image and video URLs, with owner controls for media type, publication, and deletion.
